# Windows Terminal colour schemes

Install once (PowerShell), from this `terminal` folder:

    $d="$env:LOCALAPPDATA\Microsoft\Windows Terminal\Fragments\richard-themes"; mkdir $d -Force; copy .\richard-themes.json $d

Restart Windows Terminal, then Settings > profile > Appearance > Color scheme.
Solarized Dark/Light and One Half Dark/Light are built into Windows Terminal already.
